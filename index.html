AI / Computer Vision

AEGiSS

GitHub

The problem

Spotting crowds, fire and weapons on camera feeds normally needs a person watching every stream.

What I built

A surveillance platform that runs three YOLO models (crowd, fire, firearms) on uploaded video and live webcam feeds, and pushes alerts to a real-time dashboard. Detections are stored in SQLite and Firebase for auditability.

  • Django
  • YOLOv12
  • OpenCV
  • Firebase
  • Django Channels
  1. INPUTUploaded video or live webcam (MJPEG via OpenCV)
  2. DETECT3 YOLO models; 75% confidence on uploads, 85% on live
  3. STREAMDjango Channels (ASGI) + Firebase Realtime Database
  4. ALERTDashboard with toasts, filter by label and source
AI / Platform

EventBridge AI

GitHub

The problem

Community-led events across a city are scattered, so communities struggle to run them and people struggle to find the right ones.

What I built

One platform where communities such as IEEE, GDSC and ACM manage the full event lifecycle, and users get an AI-powered feed: semantic search on vector embeddings, personalized recommendations, and real-time notifications, with an admin panel for moderation.

  • Laravel
  • Python / Django
  • LangChain
  • OpenAI Embeddings
  • Qdrant
  1. EVENTSCommunity-created events (Laravel + MySQL)
  2. EMBEDOpenAI embeddings from the Django AI engine
  3. VECTOR STOREQdrant semantic search
  4. FEEDPersonalized recommendations and notifications
HealthTech / EdTech

Speech Pro

GitHub

The problem

Speech therapy practice needs structure and instant feedback between sessions.

What I built

A therapy platform where patients work through sequential exercises: they record themselves in the browser against an expected text and get instant feedback. Each finished exercise unlocks the next, with separate login guards for patients and admins.

  • Laravel 12
  • Google Cloud TTS
  • ElevenLabs
  • MediaRecorder API
  • Alpine.js
  1. PROMPTAudio generated with Google Cloud TTS and ElevenLabs
  2. RECORDIn-browser capture, no plugins (MediaRecorder)
  3. SCORESimilarity to expected text, 85% pass threshold
  4. PROGRESSNext exercise unlocks; full therapy marked complete
